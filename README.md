# Joshua Cowell

Third-year Design Engineering MEng student at Imperial College London. I build end-to-end machine learning systems, mostly in ML, AI, and software.

I like building things that run end to end, with real data behind them and an interface someone can actually use. A lot of my time goes into the less visible parts: cleaning the data, checking that the metrics mean what I think they mean, and making sure things hold together when the project gets bigger.

## Featured projects

| Project | What it does | Headline result |
|---|---|---|
| [**TerraTrace**](https://github.com/joshuacowellcay/terratrace) | Detects forest loss in Sentinel-2 satellite imagery and shows it on an interactive map | **+8.2 IoU** over a calibrated NDVI baseline, about **+20** on cloudy tiles |
| [**The AI Physicist**](https://github.com/joshuacowellcay/ai-physicist) | Recovers the governing equation of a physical system from its motion, as readable maths | **6 / 6** systems recovered exactly; **0.18%** mean error on fitted constants |
| [**Neural Compressor**](https://github.com/joshuacowellcay/neural-compressor) | Lossless compressor: a small Transformer predicts each byte, an arithmetic coder encodes it | **1.995 bits/byte** on unseen text, **42% smaller** than `gzip -9` |

Each repo has its own README with the full results, architecture, and setup steps.
